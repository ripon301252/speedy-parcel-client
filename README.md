# 🚚 Speedy Parcel - Courier Management System

A full-stack **parcel delivery management system** where users can send, track, and manage parcel deliveries easily.

---

## 🚀 Features

- 📦 Create parcel delivery request
- 🧾 Track parcel status
- 👤 Users can apply to become a rider
- 🛠 Admin dashboard (manage deliveries)
- 🔄 Update delivery status
- 📱 Responsive UI

---

## 🛠️ Tech Stack

- React.js / Next.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
